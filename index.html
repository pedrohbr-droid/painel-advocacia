Como funciona a adição de membros?

  • 1. A Senha Provisória: É você (Administrador) quem define esta primeira senha (ex: "mudar123") e informa ao novo colaborador de forma privada junto com o link do painel.
  • 2. Acesso ao Sistema: O novo advogado usará o e-mail cadastrado e essa senha para fazer o login. Se esquecer, poderá usar a função "Esqueci minha senha" na tela inicial para redefinir.
  • 3. Liberação no Banco de Dados (⚠️ Importante): Lembre-se que por segurança, o banco de dados é selado. Após criar a conta aqui, você deve ir no painel do Firebase > Firestore > Regras e adicionar o e-mail do novo colaborador na lista de permissões. Sem isso, ele entrará no sistema mas verá a tela vazia.
